# ROM Storage Folder / Папка для ROM файлів

Помістіть сюди ваші файли образів ігор (ROMs):
- **NES / Dendy / Famicom**: `.nes`
- **Game Boy**: `.gb`
- **Game Boy Color**: `.gbc`
- **Game Boy Advance**: `.gba`
- **Super Nintendo (SNES / SFC)**: `.sfc`, `.smc`

Будь-який файл, доданий у цю папку (`/public/roms/`), автоматично відображатиметься в емуляторі у списку доступних локальних ROM-файлів для запуску в один клік!
